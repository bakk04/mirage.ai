Core Engineering

Everything You Need for Touchless Web Browsing

Built from the ground up for Chrome Manifest V3, optimizing performance and privacy through edge machine learning.

Hand Tracking & Gestures

Continuous smooth navigation. Pinch thumb and index to trigger synthetic click sequences, or raise a peace sign for zero-latency inertia scrolling.

Air Writing (CNN)

Write letters mid-air with your index finger. Trajectories are normalized into 28x28 matrices and classified by an on-device TensorFlow.js CNN for direct input injection.

• EMNIST Alphabet (A-Z)

Smart Reader (Gemini)

Condense dense articles and documentation in seconds. Extract page DOM content cleanly and generate instant contextual summaries via Google's Gemini 2.5 Flash API.

Natural Interaction

Gesture Recognition Dictionary

Three ergonomic hand postures engineered for maximum comfort and zero false-positive activation.

👌

Pinch to Click

HOVER $\to$ CLICK_PINCH

Bring your index and thumb tips together. Triggers a full W3C synthetic click sequence (pointerdown, mousedown, pointerup, click) with an instant audio click confirmation.

✌️

Two-Finger Scroll

SCROLL_V Gesture

Extend both index and middle fingers (Victory sign). Moving your hand vertically scrolls the webpage up or down proportionally with configurable sensitivity.

☝️

Air Writing

WRITE State

Extend only your index finger with thumb and other digits folded. Draws a luminous neon path on the screen and injects predicted characters directly into focused input fields.

System Engineering

Three-Tier Manifest V3 Architecture

Strict separation of concerns between vision inference, machine learning pipelines, and DOM synchronization.

01 // VISION LAYER

Local MediaPipe Vision Task running over Wasm simd. Detects 21 3D hand landmarks per frame with mirror-mode adjustment.

Camera $\to$ Wasm $\to$ Landmarker
02 // ML ENGINE

Adaptive 1€ jitter filtering, finite state hysteresis classifier, and TensorFlow.js 28x28 EMNIST letter predictor.

Signal $\to$ TFJS CNN $\to$ Class Index
03 // DOM & AUDIO

Synthetic W3C PointerEvents, smooth scrolling, Web Audio oscillator clicks, and controlled input injection.

DOM Inject $\to$ AudioContext $\to$ Input
